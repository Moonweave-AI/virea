# ✦ VIREA visual assets

The user-supplied [banner](virea-banner.png) anchors the documentation design. It is copied without alteration.

## Palette

| Role | Color |
|:--|:--|
| Charcoal background | `#151722` |
| Smoky gray-violet | `#383747` |
| Moonlight silver-lilac | `#BDB8D1` |
| Warm rose / champagne accent | `#C9ADB8` |
| Readable foreground | `#F2EDF1` |

The navigation uses a shared rounded glass silhouette, fine silver border, restrained highlights and line icons. Architecture diagrams use the same family of colors. The [feature triptych](features.png) is an editorial illustration; the actual system diagram is defined in Mermaid in the architecture guide.

## Production notes

The five navigation assets and feature illustration were created with the built-in image generation tool. Each navigation asset is a separate image. Matching edits use the supplied banner as the palette reference and preserve the exact label, icon and layout.

The final art-direction prompt: “Charcoal near-black, smoky gray-violet, silvery muted lilac, and small dusty rose/champagne highlights. Replace neon beams with soft silver-violet moonlight. Match the supplied banner's cinematic atmosphere, materials and quiet refined mood. Preserve the composition and exact navigation text.”

The banner's original filename is `codex-clipboard-6d0dbf04-6b94-4b15-978a-838fc1f7185b.png`. Generated files are checked into this directory so README rendering does not depend on an image-generation service.
