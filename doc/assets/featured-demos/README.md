# 🎞️ Current films and recordings

The [README](../../../README.md) features the English launch film and one current recording from each workspace. All footage was captured from VIREA; this revision edits the existing takes without recording new cases.

| Video | Contents | Original format |
|:--|:--|:--|

| Motion Lab | PRISM followed by SentiAvatar, source skeleton and target avatar together | 3840 × 2160 · 30 FPS |

## Playback and editing

The README uses GitHub video attachments for inline playback. The launch film's 1080p web edition fits the attachment limit; its 4K master is linked directly below the player. The two browser demos retain 4K. The VRChat web edition retains its native dimensions with lighter compression. Demo clips have no audio; the film includes English narration, music and captions. Playback starts paused.

The media release includes a music version, a narration-and-effects version, a silent version, a cover image, subtitles and the editable Remotion/workbench project. The same 3,795-frame video stream is used in all three 4K editions. Source code and required footage are packaged together; model weights, account configuration and the source VRM are excluded.

The earlier recording collection remains available under [complete recordings](../../demos/recordings.en.md).
