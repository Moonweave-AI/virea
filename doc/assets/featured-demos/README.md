## Playback

The README uses GitHub video attachment URLs, which render native players. Relative MP4 links open a repository file page instead. All selected videos use H.264; players start paused and muted. Local copies make the collection available outside GitHub too.

## Original supplied files

The VRChat original was supplied as `149ed3cf78e45dc21fccf6c1ef27dda9.mp4`; the Motion Lab original as `22f05c58578b4b6d18b9ae0f430dbe30.mp4`. Both copies retain the supplied bytes. Encoding the web edition changes compression and audio packaging only; it does not synthesize motion, cut scenes or change playback speed.
