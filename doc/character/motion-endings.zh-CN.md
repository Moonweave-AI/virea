# 动作结束：从冻结末帧到减速收势

这是最初仅对整句末段收势的实验记录。用户随后明确要求每个动作片段均回到自然姿态；
当前执行规则及验证见[每段回到自然姿态](segment-rest.zh-CN.md)，下方数据保留为历史对照。

在 RTX 5090 Laptop 上生成打招呼、解释、道别三组真实语音和动作，并在 Chrome 中播放。
旧版末帧分别留下闭眼、双臂高举、手停胸前的问题。播放器只有片段入口过渡，
结束时直接暂停动画，嘴部清零，其他表情则保留最后一个值。

修复后使用**同一组 WAV、VRMA 和面部轨迹**重播，排除重新生成动作的随机差异。
以下角速度是身体、手臂与手腕中最大的相邻采样局部角速度，取停止前最后一个有效采样区间；
它检验骤停，不是动作自然度评分。原始逐帧记录保存在外部证据目录，
资源摘要和测量汇总见[机器可读证据](evidence/endings-20260927.json)。

| 实例 | 原来停止前角速度 | 修复后停止前角速度 | 收势时长 |
| --- | ---: | ---: | ---: |
| 打招呼 | 22.70°/s | 0.17°/s | 0.91s |
| 解释 | 122.48°/s | 0.94°/s | 1.27s |
| 道别 | 69.65°/s | 0.47°/s | 1.39s |

## 执行语义

`continues` 标记同一句是否还有后续窗口，预生成包与待播放包保持一致。
中间窗口继续原生轨迹，只在整句最后一个窗口追加收势。旧包未包含该字段时视为单独一段。

收势从动画末端姿态及角速度开始，通过四元数 Hermite 修正减速到放松站姿；
时长按姿态差限制在 0.65–1.6 秒，不需要额外模型推理，不增加首播等待。
保留地面位置、骨盆朝向与手指形状，骨盆高度平滑回到角色站立高度。
口型和眨眼在 180ms 内释放，情绪表情随身体收势放松。

语音、面部、骨骼、字幕和收势都读同一音频输出时钟。语音与字幕先结束，
动作轨道继续显示收势，完成回执在收势之后提交实际姿态。
收势期间暂停 400ms 时姿态和时钟保持不变；打断后也保持当时姿态，旧播放不会补交完成回执。
没有背景定时器在暂停或打断后偷偷恢复骨骼。

收势结果不能反向编码为 SentiAvatar RVQ 历史，因此句末清空模型尾码；
句内仍使用前段原生历史。下一句通过实际骨骼姿态接入。
这是一层播放修正，尚未实现学习式收势、足部 IK 或持续呼吸待机，收势完成后仍保持姿态。

## 复现

启动 GPU 服务与 Vite 开发服务器后执行：

```powershell
pnpm --filter @virea/web dev --port 5173
# 在另一个终端采集真实资源，再重播固定资源。
node scripts/character/ending_e2e.mjs <AVATAR.vrm> <EVIDENCE>/capture
node scripts/character/ending_e2e.mjs <AVATAR.vrm> <EVIDENCE>/replay <EVIDENCE>/capture
node scripts/character/continuous_e2e.mjs <AVATAR.vrm> <EVIDENCE>/continuous
```

测试记录逐帧姿态、截图和视频；不把 VRM 或派生媒体提交到仓库。
数学回归验证入口速度、零速度终点、地面位置和朝向、绝对时钟采样及表情释放。
编排回归验证末段标记、回执前不推进历史、收势后原生历史失效。

42 项角色编排测试、92 项前端测试通过，TypeScript 构建和 Ruff 通过。
真实长回复的三个窗口标记为 `true / true / false`；前两个窗口没有收势尾部，
最后一个窗口收势 1.47s。单独复测时，两处分段语音间隔均为 105ms，暂停各轨一致，
打断后下一次动作生成用时 1.88s。

同时运行全套浏览器测试的一次实播，首处分段等待达到 5.28s，超过 250ms 验收阈值；
该失败记录仍保留，不能据后续通过承诺负载下永不缺帧。该次中间窗口的动作时长与语音一致，
没有误插入收势。前端全套首次运行另有一个工作室启动轮询时序用例失败，
随后单独复测与全套 92 项复测均通过；本次没有修改那条工作室路径。
