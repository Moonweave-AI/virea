# DisCoRD CPU runtime / CPU 运行环境

Locked whole-model CPU wrapper for Windows, Linux, macOS Intel, and macOS Apple
Silicon. It contains no CUDA-only inference call.

这是覆盖 Windows、Linux/WSL、Intel macOS 与 Apple Silicon macOS 的锁定
整模型 CPU 环境，其中不包含仅限 CUDA 的推理调用。
