# MoMask CUDA 12.8 runtime / CUDA 12.8 运行环境

Locked NVIDIA CUDA 12.8 wrapper for Windows and Linux. It executes the shared
immutable MoMask inference closure.

这是覆盖 Windows 与 Linux/WSL 的锁定 NVIDIA CUDA 12.8 环境，执行共享且
不可变的 MoMask 推理闭包。
